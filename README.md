# StudyPulse —  Οργανωτής Μελέτης
Ένα responsive, clickable mockup για φοιτητικό βοηθό οργάνωσης μελέτης.

Το `index.html` εκτελείται  σε (browser)

## Περιγραφή
Το Το StudyPulse είναι εφαρμογή με στόχο να βοηθήσει τους φοιτητές να οργανώσουν καλύτερα το διάβασμά τους 
Ο χρήστης μπορεί να προσθέτει εργασίες και να βλέπει τις προθεσμίες τους και τις δραστηριότητές του σε ένα οργανωμένο περιβάλλον.
Ένα από τα βασικά χαρακτηριστηκά της εφαρμογής είναι ότι προτείνει στον φοιτητή ποιες εργασίες είναι καλό να γίνουν πρώτα 
λαμβάνοντας υπόψιν παράγοντες όπως προθεσμία και δυσκολία αλλά και παρέχει μια εκτιμησή για το ποιες από αυτες θα τον καθυστερήσουν περισσότερο.
Η εφαρμογή αποτελεί ένα διαδραστικό πρωτότυπο (interactive mockup), στο οποίο οι έξυπνες προτάσεις και οι προβλέψεις παρουσιάζονται μέσω ενδεικτικής λογικής προσομοίωσης.  

## Τι περιλαμβάνει
- Αρχική σελίδα με μετρήσεις και εκκρεμότητες
- Προσθήκη εργασίας με μάθημα, προθεσμία, ώρες και δυσκολία
- Σήμανση εργασιών ως ολοκληρωμένων
- Προτάσεις μελέτης με απλή βαθμολόγηση προτεραιότητας
- Demo εκτίμησης κινδύνου προθεσμίας
- Ρυθμίσεις ονόματος και ημερήσιου στόχου
- Responsive πλοήγηση για desktop και mobile

## Recommender system
Προτείνει ποιο μάθημα να μελετήσει ο φοιτητής, λαμβάνοντας υπόψη την προθεσμία, τη δυσκολία και την εκτιμώμενη διάρκεια.

## Predictive model
Εκτιμά αν ο φοιτητής κινδυνεύει να μην ολοκληρώσει μια εργασία εγκαίρως, με βάση τον χρόνο που απομένει και τον απαιτούμενο φόρτο.  

## AI / έξυπνη λειτουργία
Το recommender και η εκτίμηση κινδύνου είναι προσομοιώσεις βασισμένες σε απλούς κανόνες.
Τα δεδομένα είναι demo και χάνονται όταν ανανεωθεί η σελίδα. Δεν υπάρχει login, cloud storage ή πραγματικές ειδοποιήσεις.
